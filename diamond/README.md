# 💎 Diamond — Narrated Review Engine

<div dir="rtl">

موتوری که کنار تو می‌نشیند: سایت یا وب‌اپ در حال ساخت را باز می‌کنی، با ماوس اشاره می‌کنی و حرف می‌زنی. Diamond همزمان صدا، حرکت ماوس، کلیک‌ها، ساختار و استایل همه‌ی صفحاتی که باز می‌کنی و داده‌های کارایی را ضبط می‌کند. بعد می‌فهمد هر حرفت درباره‌ی کدام عنصر بوده، ایرادهایی را که خودش هم پیدا می‌کند اضافه می‌کند، هر ایراد را تا فایل و خط کد دنبال می‌کند و برای هر کدام یک «بریف اصلاح» برای ایجنت می‌نویسد.

> این پوشه عمداً **کاملاً مستقل** از PQE است (پکیج، تست و مستندات جدا) تا بعداً بی‌دردسر به ریپوی خودش منتقل شود. تنها نقطه‌ی اتصال، خروجی سازگار با PQE است.

## چه چیزهایی را می‌سنجد

| لایه | چه می‌کند |
|---|---|
| 🎙️ روایت | گفتار فارسی محاوره را به متن با زمان هر کلمه تبدیل می‌کند و دسته و شدت را تشخیص می‌دهد |
| 🖱️ هم‌ترازی | کلمه‌های اشاره‌ای مثل «این» و «اینجا» را به عنصر زیر ماوس در همان لحظه وصل می‌کند |
| 🎨 یکدستی | رنگ‌های تقریباً یکسان، تعداد اندازه‌ی فونت، سبک‌های مختلف دکمه، فاصله‌های خارج از گرید، در همه‌ی صفحات |
| 🖐️ تعامل | کلیک بی‌اثر، کلیک‌های عصبی، خطاهای کنسول و درخواست‌های ناموفق |
| ⚡ کارایی | پرش چیدمان، پاسخ کند به کلیک، فریم‌های طولانی همراه با اسکریپت مسئول |
| 🎞️ انیمیشن | ترنزیشن روی خاصیت‌های چیدمانی، مدت طولانی |
| ♿ دسترس‌پذیری | کنتراست، اندازه‌ی هدف کلیک، دکمه‌ی بی‌نام، تصویر بی‌متن جایگزین، و در صورت تنظیم، axe-core |
| 🔁 راست‌به‌چپ | صفحه‌ی فارسی بدون جهت راست‌به‌چپ، متن فارسی چپ‌چین، اعداد لاتین |
| 🏗️ معماری | رنگ هاردکد بیرون از توکن‌ها، کامپوننت‌های بزرگ، مسیرهای کاملاً کلاینتی در Next.js |
| 🔍 ریشه‌یابی | عنصر به فایل و خط کد، با درجه‌ی اطمینان و روش پیدا کردن |

هر عددی که مبنای ایراد است، منبعش را هم می‌گوید: یا استاندارد منتشرشده (WCAG، Core Web Vitals) یا پیش‌فرض قابل‌تغییر.

## ⚡ اجرای یک‌دستوری (روش اصلی)

به هر هوش مصنوعی‌ای که به ترمینال مک دسترسی دارد فقط بگو:

> «موتور دایموند رو از توی درایو فراخونی کن برای همین پروژه»

دستورالعمل کامل برای هوش مصنوعی در فایل DIAMOND-FOR-AI.md است (یک نسخه‌اش در پوشه‌ی درایو هم هست). پشت صحنه فقط این راه‌انداز اجرا می‌شود:

</div>

```bash
bash diamond-run
```

<div dir="rtl">

راه‌انداز خودش موتور را پیدا می‌کند (پوشه‌ی سینک‌شده‌ی درایو، پوشه‌ی دانلود، یا گیت‌هاب)، اولین بار نصبش می‌کند و بعداً با آمدن نسخه‌ی جدید خودش به‌روز می‌شود. سرور توسعه‌ی پروژه را پیدا یا روشن می‌کند، پنجره‌ی بازبینی را باز می‌کند، و در پایان گزارش را باز و سرور را خاموش می‌کند. گزینه‌های مهم:

</div>

```text
--doctor         فقط نشان بده چه کار می‌کند
--smoke 20       بررسی خودکار بدون انسان، ۲۰ ثانیه
--url URL        آدرس دستی
--analyze-last   تحلیل دوباره‌ی آخرین جلسه
--install-self   نصب دائمی دستور diamond-run
```

## ریشه‌یابی دقیق در Next.js و React

بدون هیچ تنظیمی، Diamond با جستجوی متن، شناسه و کلاس در ریپو فایل‌های احتمالی را پیدا می‌کند و درجه‌ی اطمینان را پایین اعلام می‌کند. برای اطمینان کامل (فایل، خط و ستون دقیق، حتی در React 19 که اطلاعات منبع داخلی را حذف کرده) پلاگین code-inspector را فقط در حالت توسعه نصب کن:

</div>

```bash
npm i -D code-inspector-plugin
```

<div dir="rtl">

برای Next.js نسخه‌ی ۱۵ به بالا با Turbopack، در فایل تنظیمات Next:

</div>

```js
// next.config.js
const { codeInspectorPlugin } = require('code-inspector-plugin');

module.exports = {
  turbopack: { rules: codeInspectorPlugin({ bundler: 'turbopack' }) },
};
```

<div dir="rtl">

برای Next.js با Webpack (نسخه‌های قدیمی‌تر):

</div>

```js
// next.config.js
const { codeInspectorPlugin } = require('code-inspector-plugin');

module.exports = {
  webpack: (config, { dev }) => {
    if (dev) config.plugins.push(codeInspectorPlugin({ bundler: 'webpack' }));
    return config;
  },
};
```

<div dir="rtl">

⚠️ بعد از نصب، یک عنصر را در DevTools باز کن و اسم ویژگی‌ای که پلاگین اضافه کرده را ببین. اگر با پیش‌فرض Diamond فرق داشت، در فایل تنظیمات پروژه اضافه‌اش کن (پایین را ببین). Vue، Svelte، Vite، Astro و Nuxt هم با همین پلاگین پشتیبانی می‌شوند.

## تنظیمات پروژه

فایل اختیاری در ریشه‌ی ریپوی پروژه:

</div>

```toml
# .diamond.toml
source_attributes = ["data-insp-path", "data-source"]
axe_script = "node_modules/axe-core/axe.min.js"
visual_critic = false          # true = نقد بصری با مدل (هزینه‌ی توکن دارد)

[thresholds]
max_button_variants = 5        # هر تغییر آستانه به‌عنوان «تصمیم پروژه» در شواهد ثبت می‌شود

[speech]
provider = "auto"              # auto | mlx | faster | openai | none
model = "large-v3-turbo"

[routing]
light = "claude-haiku-5-5"
standard = "claude-sonnet-5-5"
heavy = "claude-opus-5-5"
```

## اتصال به هوش مصنوعی (MCP)

هر ابزاری که MCP می‌فهمد (Claude Code، Claude Desktop، Cursor) می‌تواند Diamond را صدا بزند. اضافه کردن به Claude Code:

</div>

```bash
claude mcp add diamond -- diamond mcp
```

<div dir="rtl">

ابزارها: شروع بازبینی، توقف و تحلیل، تحلیل دوباره، فهرست ایرادها، و بریف اصلاح یک ایراد. اسکیل‌های آماده برای Claude Code در پوشه‌ی skills هستند: یکی برای اجرای بازبینی و یکی برای اصلاح ایرادها.
